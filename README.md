# Lern-Pomodoro releases

Release APKs and the update manifest (`latest.json`) for the Lern-Pomodoro Android app, plus the web app for PC on the `gh-pages` branch. No source code.

- Android: download the newest APK under [Releases](https://github.com/kxxami/pomodoro-releases/releases/latest). The app updates itself after that.
- PC: open <https://kxxami.github.io/pomodoro-releases/> and install it from the browser menu ("Install app").
